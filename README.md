## SAR使用说明
SAR这部分功能是独立出来的，因为它只需要一个小区域，区别于 InSAR 和 DInSAR 需要大幅场景进行干涉，这里只需要灰度图，因此这里是直接重建的适用于JPG格式的数据库
- SAR功能的输入必须是JPG图片
- Speckle Denoise 这里应该输入sea杂波图片，框选则随意
- Clutter Suppression 则是需要输入ship图片，目标区域为高亮区域，杂波区域为暗色区域
- Target Detection 和Batch Target Detection 则随便输入图片，因为只是做目标识别

## 本分支主要变化

### 1. 新增 Macao 导入节点

在工作流节点界面中新增了Macao数据导入节点。
新增内容包括：

- Macao 单文件导入节点
- Macao 批量导入节点

### 2. 统一工作区数据模型
之前的我看了一下，工作流和工作区看起来建了两套数据库。会导致导入工程但在工作区的项目区域不显示，所以我统一使用了同一套，但是工作流界面我还没有测试

现在工具窗口会接收统一的 `QStandardItemModel`，这样从工作区导入或打开的数据可以被目标检测、批量目标检测等工具直接使用。

### 3. 新增单张目标检测功能

新增`Target Detection`界面，用于对单张 SAR 图像进行目标检测。（本来预想的好像也是多个模型，目前只实现了一个）

当前功能包括（也就是使用流程）：

- 从共享数据库树中选择工程/数据节点
- 从当前数据节点中选择输入图像
- 选择 ONNX 检测模型
- 输入置信度阈值
- 加载并预览原图
- 运行目标检测
- 显示检测结果和舰船概率


### 4. 新增批量目标检测功能

新增`Batch Target Recognition`界面，用于对一个数据节点中的多张图像进行批量检测。但目前只支持单节点，不知道后面需不需要多节点导入。
以当前为例，批量检测流程：
1. 选择工程。
2. 选择数据节点。
3. 点击添加数据。
4. 右侧表格显示导入数据：
5. 点击开始检测。
6. 程序逐张图像执行检测，并逐行更新结果表格。
7. 点击表格中的文件名，可在预览区域显示对应图像。
8. 支持将批量检测结果导出为 CSV 文件。

注意，我一开始觉得可以选择真值导入方式，但现在只做到了真值从文件名中自动解析：（后面根据情况再调整）
- 文件名包含`ship`，真值为`Ship`
- 文件名包含`sea`，真值为`Sea`
- 其他情况为 `Unknown`

## C++ 标准设置说明

不要给整个工程开启 C++17。
只有以下两个文件因为使用了 ONNX Runtime C++ API，需要单独设置为 C++17：

- `TargetDetection.cpp`
- `BatchTargetRecognition.cpp`
